Companion Mod
Coming later · optional

A future power-user upgrade

SpireVault works end-to-end in your browser today. You don't need any install to share runs, race the daily, ask Coach, or run a tournament.

The Companion mod is a future opt-in upgrade that will unlock live spectator data and live AI coaching for streamers. It's not the way you use SpireVault — it's the upgrade for the people who want their stream to read their hand in real time.

What you can already do without it

  • Share runs — drop your .run save on the home page and your run lands in Replays and your profile feed.
  • Race the daily — submit today's run on /race straight from the browser. No install.
  • Ask Coach — screenshot a card reward and Coach grades each pick, no game state required.
  • Run a tournament — spin up a 4- or 8-team bracket on /tournaments and share the link.

What the mod will add (later)

Live spectator URLs

Share a /watch link that updates in real time as you play — deck, hand, HP, party state. For streamers who want their chat to see what's in their hand.

Live AI coaching

Coach reads the live game state instead of a screenshot. Useful for runback streams and tournament casters.

OBS Browser Source overlay

One URL into OBS, a polished animated overlay out. Lower-third style, no Twitch handshake.

Cloud damage meter

Skada-style damage breakdown readable from your phone or a second monitor.

For developers · build it from source

The Companion mod source lives in the SpireVault repo under Mod/SpireVaultCompanion. .NET 9.0, depends on BaseLib-StS2. The sts2-modding-mcp is wired into the project for AI-assisted contributions. Public Nexus / Steam Workshop releases are pending the v0.1 signing checklist.

  • v0.1 · Steam Rich Presence sync + damage meter (in progress)
  • v0.2 · teammate decks + live party hub mirror
  • v0.3 · auto-share post-run + Discord LFG auto-post

Privacy posture: the mod streams the current run state only (deck, hand, HP, floor, party). Nothing leaves your machine until you sign in and start a run with the mod enabled. You can disable streaming for any single run from the in-game ModConfig tab. Run state expires from the SpireVault cloud automatically — live in 90 seconds, post-run replay window 30 minutes.

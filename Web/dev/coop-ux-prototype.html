Host checklist

  1. Paste Discord LFG post — drop it in your STS2 LFG channel
  2. Join voice — be in LFG 1 before players arrive
  3. Open STS2 — Multiplayer → Host → choose mode
  4. Accept Steam friend requests — joiners will add you
  5. Mark Character Select once everyone is in voice
  6. Mark In Game once the run has started
